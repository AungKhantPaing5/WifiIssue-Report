# Campus Connect Hub

I will now generate a fully functional, modern single-file Web Application for the Campus Internet Issue Reporting & Admin Portal in Burmese (and English labels).

This web application includes:

Authentication UI: Google/Outlook login simulations, plus direct toggle between Student Portal and Admin Panel.

Student Portal: Profile display, comprehensive Issue Reporting Form (with screenshot uploads for both issue & WiFiman speedtest result), My Reports History, and direct Chat with Admin.

Admin Panel: Dashboard metrics, detailed ticket table with timestamp, image lightboxes, status manager, Excel export (SheetJS), PDF export (html2pdf.js), and student chat module.

Interactive State & Storage: localStorage integration so reports created by students instantly reflect in the Admin Dashboard with full persistence.
